# DOA Estimation Based on Improved Complex-Valued Bivariate Iterative Hard Thresholding - [Includes MATLAB Code]

Introduction: The estimation of Direction of Arrival (DOA) using sensor arrays has been a research hotspot in fields such as communication, radar, and speech signal processing [1-4]. Accurate DOA estimation often requires high-resolution quantization, which is a strict requirement for Analog-to-Digital Converters (ADC). Reducing the number of bits in quantization can significantly reduce power consumption and errors caused by nonlinear components [5]. As a special case, only retaining one bit per input symbol for ADC has been widely used in Multi-Input Multi-Output (MIMO) systems [6-11].
In recent decades, many 1-bit DOA estimation methods have been proposed. According to the Law of Sines, Bar-Shalom reconstructed the unquantized covariance matrix and utilized the Minimum Variance Distortionless Response (MVDR) algorithm to estimate DOA [13]. In the literature [14], Liu estimated the normalized covariance of unquantized data using the Law of Sines and designed a sparse array to achieve more accurate DOA estimation. Huang proved that the covariance matrix of a 1-bit array observation is an approximation of a non-quantized covariance matrix whose error can be ignored, and the MUSIC algorithm can be directly used for 1-bit DOA estimation [15]. In the literature [16], Li extended the relationship between the covariance matrices of 1-bit observations and unquantized observations to the tensor domain and proposed a 1-bit parallel factor analysis (PARAFAC) estimator that can simultaneously solve DOA and frequency. Yoffe derived the maximum likelihood (ML) estimator for 1-bit DOA estimation and proposed an inferior method [17].
Sparse representation can reconstruct signals with less measurement using structured information, and it can also be used to reduce the number of quantization bits. In [18], Stockle proposed the Complex-Valued Iterative Hard Thresholding (CBIHT) algorithm, which extends the binary Iterative Hard Thresholding (BIHT) algorithm [19] to complex-valued and multiple snapshots. Meng applied the Generalized Sparse Bayesian Learning (Gr-SBL) algorithm [20] to solve the one-bit DOA estimation problem [21]. Meng's method improves the recovery performance by utilizing the joint sparsity of the signal's real and imaginary parts. In [22], Gao solved this problem through a Support Vector Machine (SVM) framework. Wei proposed a robust unstructured method for denoising in [23].
Based on sparse representation theory, the CBIHT algorithm [18] outperforms traditional methods in DOA estimation. However, due to the column correlation of the array manifold, the CBIHT algorithm sometimes retains incorrect bases, thus reducing the accuracy of DOA estimation and slowing down convergence, especially when the true DOA is off-line. Inspired by CBIHT, an improved complex-valued binary Iterative Hard Thresholding (iCBIHT) algorithm was proposed. Firstly, a signal reconstruction error function was defined, and the signal was updated using gradient descent. Through complex-valued gradient descent, the real and imaginary parts of the reconstructed signal can be automatically utilized. Secondly, a space spectrum design was used to define an improved hard threshold function, and a stopping criterion for convergence was defined. Thirdly, a base update strategy was proposed to solve the off-line DOA problem. By iteratively updating the search grid and manifold matrix, the accuracy of DOA estimation was improved. Fourthly, to avoid repeated selection and abandonment of bases, a backtracking strategy was used to refine the estimated signal after hard threshold processing, which also promoted convergence. Simulations and analysis show that this method has higher DOA estimation accuracy than the 1-bit MUSIC and CBIHT methods under low signal-to-noise ratio and fewer snapshots.
In this paper, our goal is to estimate the direction of arrival (DOA) with a sensor array that has 1 bit observation. After the signal model formula is sparse representation, an improved complex-valued binary iterative hard thresholding (iCBIHT) algorithm is proposed. Firstly, we define the signal reconstruction error function and utilize the joint sparsity of both real and imaginary parts of the reconstructed signal to update the signal through gradient descent method. Secondly, we design an improved hard threshold function and a new stopping criterion to judge convergence. Thirdly, in order to solve the off-line DOA problem, we introduce a grid-based basis update strategy. By iteratively updating the search grid and array manifold, the accuracy of DOA estimation is improved. Fourthly, to avoid repeated selection and abandonment of bases, we introduce a backtracking strategy to refine the estimated signals processed by hard thresholding, which also promotes convergence. Simulations and analysis show that iCBIHT outperforms 1-bit MUSIC and CBIHT, especially under low SNR and few quick shots.
